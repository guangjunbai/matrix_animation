# 矩阵线性变换可视化

一个用 TypeScript + Canvas 手写的 2D / 3D 线性变换可视化工具。输入一个矩阵，实时观察网格、单位正方形/立方体、基向量和自定义曲线是如何被这个矩阵变换的。

## 功能

**二维 / 三维**

- 输入 2×2 / 3×3 矩阵，画面即时更新；点「播放线性变换」可从头看完整变形过程
- 单位正方形 / 单位立方体、坐标网格、基向量 e₁ e₂ e₃ 随矩阵一起变形
- 自定义向量：输入一个向量，观察它被矩阵搬到哪里（实时显示变换后的坐标）
- 自定义图形：用参数方程定义曲线（二维）或空间曲线（三维），逐点施加变换

**线性代数**

- 特征值与特征向量：2×2 解析求解；3×3 解三次特征方程，覆盖重根、复根、特征空间退化为平面等情形，并在画布上标注不变方向
- 对角化 A = P·D·P⁻¹：给出 P、D、P⁻¹ 三个矩阵，支持单步播放（×P⁻¹ → ×D → ×P）与整套连播

**交互**

- 二维：滚轮缩放（以光标为锚点）、拖拽平移、双击复位
- 三维：拖拽轨道旋转、滚轮缩放、双击复位
- 播放控制：播放 / 暂停 / 重播、进度条拖动、速度调节
- 输入框支持方向键跳格，到边界循环

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173

其他命令：

```bash
npm test        # 运行单元测试
npm run build   # 类型检查 + 打包
npm run preview # 预览打包结果
```

唯一需要提前准备的是 **Node.js** 和一个浏览器。

## 项目结构

```
src/
  math/        数学层：矩阵、向量、特征分解、对角化、表达式解析、格式化
  render2d/    二维渲染：相机、绘制原语、场景合成
  render3d/    三维渲染：轨道相机、透视投影、场景合成
  animation/   矩阵动画（二维三维共用的泛型播放器）
  ui/          面板：矩阵 / 向量 / 特征值 / 对角化 / 图形输入
  main.ts      接线与渲染循环
```
